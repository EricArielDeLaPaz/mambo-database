# Profiles

Illustrated profile pictures of people facing the camera, for personas, mockups and design work. They appear in Browse under **Profiles** and feed the **Persona generator** tool.

| Folder | Style | Artwork | License |
| --- | --- | --- | --- |
| `lorelei/` | Illustrated | Lorelei by Lisa Wischofsky | CC0 1.0 |
| `open-peeps/` | Drawing | Open Peeps by Pablo Stanley | CC0 1.0 |
| `pixel-art/` | Pixel | Pixel Art (DiceBear) | CC0 1.0 |

Each style has 40 pictures across eight skin tones (five per tone) with varied hair, hair covering, glasses and facial hair. CC0 is a public domain dedication, so the pictures can be used commercially without credit. The creator and source are still recorded in `LICENSES.json` and each folder's `LICENSE.txt`.

The pictures are drawings of invented people. They are generated with [DiceBear](https://www.dicebear.com) (MIT licensed code) by `scripts/make-profiles.mjs`, which refuses to run for a style whose license is not CC0.

## Realistic style
There are no photographs yet. A photo of a real person carries a model release and likeness question on top of the photo license, so photos are only added when the license, the release and the source are all documented. To add some, put the files in `profiles/realistic/` and record, for every file, the photographer, the license, a link to the source and whether a model release exists.
