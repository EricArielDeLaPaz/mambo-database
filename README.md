# Mambo Database

An open, structured library of UI components, color sets and typefaces with verified pairings, written for designers and AI assistants.

## How it works
Every entry is one JSON file in `entries/`. Run the build and everything else is generated:

    node scripts/build.js

| Output | Purpose |
|---|---|
| `dist/site/index.html` | Searchable site (open it directly in a browser) |
| `dist/entries/**/*.md` | One small Markdown file per entry, for AI to read (guides are in `entries/guides/`) |
| `profiles/` | Illustrated profile pictures (CC0) in three styles, generated by `scripts/make-profiles.mjs`. See `profiles/README.md` |
| `entries/documents/` | Links to official documentation for developers and designers |
| `icons/` | Curated UI icons from free, commercially usable libraries, grouped by design system, with each library's license. See `icons/README.md` |
| `guides/*.md` (source) | The Guides tab. Plain Markdown with a short front matter block (`id`, `title`, `summary`, `topic`, `level`, `order`). Add a file and rebuild |
| `dist/llms.txt` | Index for AI tools that read `llms.txt` |
| `dist/data/library.json` | All data in one file |
| `dist/skill/create-design-system/` | The `/create-design-system` skill: interviews you about the feel and platform, then picks accessible colors, type and optional components |
| `dist/skill/mambo-database/` | A ready-made agent skill (`SKILL.md` + references). Copy the folder into your skills directory |

Requires Node 18+. No dependencies.

## Add an entry
Copy `entries/components/modal-dialog.json`, edit it, run the build. Required fields are in `schema/component.schema.json`. The build checks them. Palette contrast ratios are computed automatically.

## Honest limits of this starter
- "Copy HTML + CSS" is meant for Figma importer plugins. It is not a native Figma paste. A real one-click paste into Figma is a later step.
- "My design systems" stores tokens in the browser only. There is no account or sync yet, and it cannot generate a `.fig` file. Export the JSON or CSS variables and bring them into Figma with a tokens plugin.
- Only 4 sample entries exist. Preview rendering assumes simple HTML and CSS.

## Live site
Pushing to `main` rebuilds and deploys the site with GitHub Pages (`.github/workflows/pages.yml`). The deployed site also serves `llms.txt`, `entries/`, `data/library.json`, `skill/` and `mambo-database-skill.zip`.

| Material | License | Where it is recorded |

| Icons | Each library's own license (MIT, ISC or Apache-2.0) | `icons/<library>/LICENSE`, `icons/sets.json` |
| Profile pictures | CC0 1.0 (public domain), made with DiceBear | `profiles/LICENSES.json`, `profiles/<style>/LICENSE.txt` |

| Documents | Links only; the documentation belongs to its publishers | `entries/documents/*.json` |

License files for third-party icons are kept exactly as their authors published them (for example, Carbon's Apache-2.0 file is byte-for-byte the one in the Carbon repository).

## Fonts, credits and licenses
Only typefaces under the SIL Open Font License 1.1 are listed. Copyright lines come from each font's `OFL.txt` and designers from the METADATA in [google/fonts](https://github.com/google/fonts). See `THIRD_PARTY_NOTICES.md` (generated by the build) and `licenses/OFL-1.1.txt`. Font files are not stored here; previews load from Google Fonts. Language support is calculated from each font's character set with the Google Fonts language data.
